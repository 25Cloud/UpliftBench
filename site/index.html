怎么读这张表
uplift = treatment − placebo（不是减 baseline）。headroom 是填掉了多少剩余空间；placebo 列是「上下文变长本身值多少分」。
激活率 = placebo + treatment 两臂里技能真的进了上下文的 run 占比。低的激活率会让 uplift 天然趋近 0——技能没进上下文，treatment 就是 baseline。
自动激活与强制注入是两种实验条件，同一个技能包可能各有一行，不许互相比较，也不许只挑好看的那个。
A 级（可执行验证）与 B 级（固定版本 LLM judge）分组显示，不并排排名：用不同尺子量出来的身高不能排在一起。
⚠️ = 安慰剂效应大于净增益，说明分数主要来自长度。
