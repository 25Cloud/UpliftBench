## 阶段 1：一周 MVP（下一步）

**目标**：能对 5 个真实技能包跑出完整 Tier 0 卡 + 一个真实任务集的三臂 uplift。

| 天 | 任务 | 交付 | 验收 |
|---|---|---|---|
| **D1** | 仓库骨架 + `uplift probe --only static-cost` | 能读技能包目录算 token | 对 `addyosmani/agent-skills`（25 个 skill）输出总 token + 每文件明细 + 重复检测 |
| **D2** | harness 适配层 + `uninstall-clean` | 能装/卸技能并检测残留 | 对 2 个技能包跑出 `clean: true/false` |
| **D3** | `constraint-following` | 从 SKILL.md 抽约束 + 跑任务检测违规 | 抽出 ≥10 条约束，跑出违规率 |
| **D4** | `uplift run` 三臂骨架（用 3 题假任务集） | worktree × 3、结果入 SQLite | 三臂结果可查询，`--resume` 可用 |
| **D5** | `metrics/uplift.ts` + 置信区间 + SkillCard 渲染 | 出 markdown 卡 | 单元测试覆盖 5 个手算样例 |
| **D6** | badge SVG + `uplift taskset validate` | badge 可贴 README | 渲染正常，悬停信息完整 |
| **D7** | 对 5 个真实技能包出卡 + 写 README/落地页 | 5 张卡 | 5 张卡内容合理，无明显错误 |

**D7 建议测的 5 个包**：
1. `addyosmani/agent-skills`（116k★，25 skills）

## 阶段 2：可信度（第 2–3 周）

| 任务 | 为什么重要 |
|---|---|
| 写 `web-guidance@1.0` 官方任务集（30 题） | 第一个 A 级任务集，证明 Tier 1 能跑 |
| **跑出 MWG 的 uplift，与它自己报的 +27~36pp 交叉验证** | **公信力的核弹**。数字接近 → 立刻建立信任 |
| 补 `negative-transfer` 与 `injection-resistance` | 补齐六探针 |
| 写「两臂 vs 三臂」对比实验 | 证明安慰剂臂改变了排名 → 核心传播素材 |
| 发布 v0.1 + 榜单页 | 第一次对外 |

**「两臂 vs 三臂」实验的做法**：
同一批 30 题、同一个技能包，分别用 `treatment − baseline`（两臂）和 `treatment − placebo`（三臂）算 uplift，比较排名变化。只要有一个技能包的排名发生变化，这个实验就成功了。

## 里程碑判定

| 里程碑 | 判定条件 |
|---|---|
| **M1 可用** | 5 个真实技能包出卡，无致命错误 |
| **M2 可信** | MWG 交叉验证误差 < 10pp；两臂vs三臂实验有排名变化 |
| **M3 被采用** | 有 ≥3 个外部技能包作者主动贴 badge |
| **M4 生态** | 有 ≥3 个社区提交的任务集通过准入检查 |
| **M5 可持续** | 有付费用户或赞助 |
