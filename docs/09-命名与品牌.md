## 二、`uplift` 这个词的含义

### 字面
`up` + `lift`，14 世纪出现，本义「往上举」。引申为「提升、增长、鼓舞」。

### 专业含义（这才是选它的理由）

在**因果推断与 A/B 测试**里，`uplift` 是有严格定义的术语：

```
uplift = 实验组结果 − 对照组结果
```

**它不是绝对分数，是增量。** 这个领域甚至有独立分支叫 **uplift modeling**（增益模型 / 增量模型），业界也叫 `incremental modeling`、`true lift modeling`，专门回答：

> 「因为施加了这个干预，额外多出来了多少效果？」

与本项目的三臂定义完全对齐：

```
uplift = treatment − placebo
```

### 附带的好处

uplift modeling 的核心概念是 **persuadables**，只对那些会因干预而改变的对象有效。

这恰好是技能包的真实处境：**一个好技能只对特定一类任务有用。** 只报平均分会抹平这个信息，报 uplift 就是在报「它对什么有效、对什么无效」。

## 四、为什么不叫 SkillBench

**因为已经有人用了，而且做得很好。**

- `SkillsBench` — [arXiv 2602.12670](https://arxiv.org/abs/2602.12670)，[benchflow-ai/skillsbench](https://github.com/benchflow-ai/skillsbench)，**1,917★**
- 如果我们也叫 SkillBench，会被当成它的山寨品

**换名字不是退让，是定位。** 名字里带 `uplift` 就是在宣告：**我们测的是增量，不是水平。**

## 五、badge 设计

### 5.1 精简版（README 用）

```
uplift 31%
```

9 个字符，任何 README 都塞得下。

### 5.2 完整版（榜单/详情页用）

```
uplift 31% (base 40 → treat 76, placebo 45) A级
```

### 5.3 为什么 badge 必须带 placebo

```
普通 badge:   uplift 31%
我们的 badge: uplift 31% (base 40 → treat 76, placebo 45)
```

第二行括号里的 `placebo 45` 直接暴露了安慰剂效应，**任何只写一个数字的 badge 都可能是安慰剂刷出来的**。

这个设计本身免疫「你是不是刷分」的质疑，**这本身就是最好的传播素材**。

### 5.4 颜色规则

| uplift_pp | 颜色 | 说明 |
|---|---|---|
| ≥ +15 | 亮绿 `#2ea44f` | 显著有效 |
| +5 ~ +15 | 绿 `#4c9a2a` | 有效 |
| 0 ~ +5 | 灰 `#9e9e9e` | 无可测量增益 |
| < 0 | 红 `#d73a49` | 负增益（仅在 CI 置信区间不含 0 时显示红色） |

**`placebo_effect_pp > uplift_pp` → 强制加 ⚠️ 角标**（分数主要来自长度）。

## 七、传播素材清单（提前准备）

| 素材 | 为什么有传播力 |
|---|---|
| 「两臂 vs 三臂」排名变化对比 | 直接质疑所有现有基准的数字 |
| MWG 交叉验证（我们测的 vs 它自报的 +27~36pp） | 证明方法正确 |
| `addyosmani/agent-skills` 116k★ 的第一张 SkillCard | 最大牌的无数字项目被量了 |
| 「技能包长度值多少分」排行榜（`placebo_effect` 排名） | 反直觉，有话题性 |
| 负迁移案例（某技能包领域内 +20pp、领域外 −10pp） | 揭示「装了就变强」的错觉 |

## 八、视觉识别（待定）

- 主色：待定（建议冷色调，与「测量/仪器」关联）
- Logo 概念：**天平**（减掉 placebo 的意象）或 **试金石**（条痕比色）
- 不要用：齿轮、机器人、大脑（太常见）

## 九、语言风格

- 文档：中文为主，技术术语保留英文
- 对外文案：**短句、给数字、不吹**
- 禁用词：`revolutionary`、`game-changing`、`next-generation`、`赋能`、`一站式`
- 推荐句式：`X 是多少，因为 Y，你可以 Z`
