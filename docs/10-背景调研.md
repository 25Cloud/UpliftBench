## 四、对本项目最重要的三条数据

### 4.1 星数最高的技能包，零效果数字

`addyosmani/agent-skills` — **116,785★ / 12,216 fork**，README 里 0 个 uplift 数值。

### 4.2 唯一公开数字的技能包，登顶了

`GoogleChrome/modern-web-guidance-src` — 11-13 当天 Trending 第 1（+739），全生态**唯一**公开 uplift 表（+27~36pp）。

**这是本项目最硬的立论：在一个所有项目都自称有用的品类里，唯一给出可验证数字的那个，自动获得全部注意力。**

### 4.3 卖「可验证」的技能包，自己没被验证

`cloudflare/security-audit-skill` — 7 天上榜，卖点原文 "independently verified, machine-readable findings"。

## 五、传播规律（可直接复用到本项目）

| # | 规律 | 证据 | 我们的做法 |
|---|---|---|---|
| 1 | **绑定 Claude Code / 多 harness = 免费流量** | 135 个里 40+ 在 README 列 harness 兼容矩阵 | README 第一屏就放兼容矩阵 |
| 2 | **一个数字 > 一千字功能** | MWG +27~36pp、caveman 砍 65%、headroom 60-95% fewer tokens | badge 就写 `uplift 31%` |
| 3 | **"Fork it and own it" 是增长引擎** | ai-job-search、OpenBot 白标；fork/star 比高者传播最快 | 协议开源，任何人可 fork 重跑 |
| 4 | **单作者 + 一个明确痛点也能爆** | hallmark、caveman、ponytail、impeccable | 切口小到一句话：`uplift 31%` |
| 5 | **官方下场 = 生态确认，也是清场信号** | Anthropic/Google/Cloudflare/NVIDIA/Meta/AWS/Chrome 30 天内全发技能包 | 不跟官方撞技能，去补官方不做的测量层 |

## 六、Tier 0 探针 5 的候选通用任务来源
